# HOUSLY

A modern and responsive website developed for an architecture studio, combining minimalist visual design with interactive front-end features.

## About

This project was created to showcase an architecture company's work, services, and projects through a visually focused and immersive website.

The interface was designed with an emphasis on typography, visual hierarchy, animations, and responsive navigation, creating a modern experience suitable for an architecture and design brand.

## Features

* Responsive design for desktop and mobile
* Interactive mobile navigation menu
* Animated header based on scroll position
* Interactive 3D hero animation
* Touch and mouse wheel support for the hero animation
* Scroll-triggered animations using `IntersectionObserver`
* Project image reveal animations
* Animated text highlights
* FAQ accordion
* Smooth scrolling navigation
* Accessibility attributes for interactive elements

## Technologies

* HTML5
* CSS3
* JavaScript
* Intersection Observer API
* Responsive Web Design

## Highlights

One of the main focuses of the project was creating an engaging first impression through the hero section.

The JavaScript controls a scroll-based 3D transformation that changes the position, rotation, and scale of the hero content. The project also uses the `IntersectionObserver` API to trigger animations as different elements enter the viewport.

## Purpose

The project was developed to practice modern front-end development techniques while creating a professional website for an architecture and design company.

It combines semantic HTML, responsive CSS, and JavaScript interactions to create a polished user experience without relying on external frameworks.
